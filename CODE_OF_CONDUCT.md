# Code of conduct

Squire is a small, friendly project. To keep it that way:

- **Be kind and patient.** People here range from first-time users to seasoned programmers. Nobody has to know everything.
- **Help, don't belittle.** Answer questions the way you'd want yours answered.
- **Disagree about ideas, not people.** No insults, harassment, slurs or personal attacks.
- **No spam, scams or selling.** Squire is free, and this space isn't for advertising.
- **Respect privacy.** Don't post anyone's personal information, and don't share your own private data in public issues.

If someone breaks these rules, the maintainer may edit or delete their comments, lock threads, or block them from the project.

To report a problem, use the [private security report form](https://github.com/sirgijoe/squire-sack/security/advisories/new) and start the title with "Conduct". Reports are kept confidential.
